Chrome extension for safer AI workflows

Protect sensitive data before it reaches AI chats

PasteSafe detects API keys, emails, URLs, IDs, phone numbers and other sensitive data when you paste into ChatGPT, Claude or Gemini — and lets you mask it before sending.

Add to Chrome View on GitHub

How it works

1. Paste text into an AI chat

PasteSafe watches for pasted content in supported chat interfaces.

2. Detect sensitive data locally

It looks for common risky patterns like API keys, emails, URLs, IDs and more.

3. Mask before sending

You can review the content and insert a safer version instead of the original.

Why PasteSafe

  • 100% local processing — no servers
  • Fast, minimal workflow
  • Built for ChatGPT, Claude and Gemini
  • Helps reduce accidental prompt leaks

What PasteSafe can detect

  • API keys
  • Email addresses
  • Phone numbers
  • UUIDs and identifiers
  • URLs
  • Financial values and other suspicious patterns
