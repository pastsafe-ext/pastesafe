Privacy Policy for PasteSafe

PasteSafe is a browser extension designed to help users avoid accidentally sharing sensitive information when pasting text into AI chat interfaces.

Data Collection
PasteSafe does not collect, transmit, or store any personal data on external servers.

All text analysis happens locally in the user's browser.

Clipboard Content
When a user pastes text into supported AI chat interfaces, the extension analyzes the pasted content locally in order to detect patterns such as:
- email addresses
- phone numbers
- API keys
- identifiers
- URLs
- financial amounts

This analysis happens entirely within the browser and no clipboard content is transmitted outside the device.

Storage
PasteSafe stores limited information locally using the browser's storage API, including:
- user settings
- protection counter
- last detection summary

This data is stored only on the user's device and is never transmitted externally.

Third-Party Services
PasteSafe does not use third-party analytics, tracking, or advertising services.

Changes
If this policy changes, updates will be reflected on this page.
