Privacy Policy

PasteSafe is a browser extension designed to prevent accidental leaks of sensitive data when pasting text into AI chat interfaces.

Data Collection

PasteSafe does not collect, transmit, or store any personal data on external servers.

PasteSafe does not collect, transmit, sell, or share user data.

Local Processing

All text analysis happens locally in the user's browser.

All detection and masking happens locally in the browser. No pasted content is transmitted to any external servers.

Clipboard Content

When a user pastes text, the extension analyzes it locally to detect patterns such as:

  • emails
  • phone numbers
  • API keys / tokens
  • identifiers
  • URLs
  • financial amounts

Storage

PasteSafe stores only minimal local settings such as:

  • user preferences
  • last detection summary
  • protection counter

This data is stored locally using the browser storage API.

Third-party services

PasteSafe does not use analytics, tracking, or advertising services.
